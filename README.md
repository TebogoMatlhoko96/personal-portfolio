# Tebogo Matlhoko — Animated Developer Portfolio

A colourful, responsive, animated portfolio website for a Junior Software Developer.

## Features
- Modern dark/neon visual design
- Responsive mobile, tablet and desktop layout
- Animated reveal-on-scroll sections
- Floating code-card animation
- Interactive desktop code-card tilt
- Mobile navigation
- Skills, projects, about and contact sections
- No build tools required

## Run locally
Open `index.html` in a browser.

For a local development server, use any static server, for example:
- VS Code Live Server
- Python's built-in HTTP server: `python -m http.server 8000`

Then visit `http://localhost:8000`.

## Personalise before publishing
Open `script.js` and replace:
- `your.email@example.com`
- `github: "#"`
- `linkedin: "#"`

You can also replace project descriptions and add your GitHub project URLs in `index.html`.

## Suggested deployment
This static site can be deployed using GitHub Pages, Netlify or Vercel.
